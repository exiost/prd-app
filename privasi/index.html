Kebijakan Privasi

Terakhir diperbarui: 8 November 2026

Halaman ini menjelaskan data apa yang dicatat saat Anda memakai PRD Generator (layanan untuk mengubah ide aplikasi menjadi PRD, daftar task, paket build, dan video), untuk apa data itu dipakai, berapa lama disimpan, dan hak-hak Anda sesuai Undang-Undang No. 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP). Layanan ini dikelola oleh pengelola PRD Generator.

1. Data yang kami catat

  • Saat ini layanan tidak mewajibkan login, sehingga kami tidak mencatat data akun Anda.
  • Isi yang Anda ketik (ide, jawaban, referensi, gambar yang diunggah, PRD) dikirim ke mesin AI yang Anda pilih untuk diproses. Pada fitur "Dari video", video dipotong menjadi beberapa gambar di perangkat Anda dan hanya gambar itu yang dikirim ke mesin AI; file video tidak diunggah. Isi ini tidak disimpan di database kami; selama diproses, isi tersebut bisa berada sementara di folder kerja server dan dihapus otomatis paling lama ±2–3 jam.
  • Riwayat PRD disimpan di browser Anda sendiri (localStorage), bukan di server. Menghapus data browser akan menghapusnya.
  • Skill racikan: bila AI meracik keahlian baru (mis. "Manajemen Peternakan") untuk menyusun PRD, panduan umum keahlian itu disimpan agar bisa dipakai ulang untuk permintaan sejenis. Yang disimpan hanya pengetahuan umum (nama keahlian, deskripsi, panduan), tanpa isi ide, nama, kontak, atau data Anda.
  • API key Claude milik Anda (opsional, bila Anda menempelnya di tombol Mesin AI): disimpan di browser Anda sendiri (localStorage). Di versi web statis ini tidak ada server: permintaan AI dikirim langsung dari browser Anda ke Anthropic lewat HTTPS; tidak disimpan, tidak dicatat, dan tidak dipakai untuk hal lain. Hapus kapan saja lewat tombol Hapus. Hal yang sama berlaku untuk API key Gemini, OpenAI, atau SumoPod milik Anda di versi ini: disimpan di browser Anda dan dikirim langsung ke Google, OpenAI, atau SumoPod hanya untuk permintaan AI Anda.
  • Pencarian skill komunitas: untuk mencari skill AI coding yang cocok, server mengirim beberapa kata kunci teknis umum (mis. "nextjs", "supabase") ke database publik skills.sh. Isi ide, jawaban, PRD, nama, atau email Anda tidak dikirim.
  • Akun kredit (bila Anda masuk dengan Google untuk memakai/membeli kredit): email, nama & foto profil Google, saldo kredit, riwayat pembelian (paket, nominal, status, metode bayar dari Midtrans), dan catatan pemakaian AI berupa jenis langkah, model, dan jumlah token saja. Isi ide, jawaban, PRD, atau gambar Anda tidak disimpan: saat memakai kredit, permintaan lewat server kami (Supabase) hanya untuk diteruskan ke Anthropic lalu dihitung biayanya.
  • Log teknis server standar dari penyedia hosting (mis. alamat IP, waktu akses) yang dipakai untuk keamanan & perbaikan gangguan.

2. Untuk apa data dipakai

  • Menjalankan layanan: membuat PRD, task, paket build, dan video sesuai permintaan Anda.
  • Menjaga keamanan dan memperbaiki gangguan.

Kami tidak menjual data Anda dan tidak memakainya untuk iklan.

3. Pihak lain yang terlibat

  • Penyedia AI yang Anda pilih — mis. Anthropic (Claude), Google (Gemini), OpenAI, SumoPod — menerima isi permintaan Anda untuk diproses dan tunduk pada kebijakan privasi masing-masing.
  • Bila Anda memakai Penghubung AI (agy / Claude CLI / Codex di komputer Anda sendiri): permintaan dikerjakan oleh aplikasi resmi tersebut di komputer Anda memakai akun Anda; token login aplikasi itu tidak pernah dikirim ke server kami. Pada versi GitHub Pages (tanpa server), browser Anda memanggil Penghubung AI langsung di komputer yang sama (alamat 127.0.0.1), sehingga permintaan tidak melewati server mana pun sebelum dikerjakan aplikasi CLI tersebut.
  • skills.sh — database publik skill AI coding; hanya menerima kata kunci teknis pencarian. Skill yang Anda pilih dipasang dari GitHub oleh AI coding di komputer Anda saat membangun aplikasi.
  • Supabase — tempat akun, saldo kredit, dan riwayat pembelian disimpan; juga meneruskan permintaan AI mode kredit ke Anthropic.
  • Midtrans — memproses pembayaran (QRIS, e-wallet, transfer bank, kartu). Data pembayaran Anda diisi langsung di halaman Midtrans, tidak lewat kami.
  • Penyedia hosting tempat layanan ini berjalan.

4. Cookie

Kami hanya memakai cookie yang diperlukan agar layanan berfungsi (bukan untuk iklan/pelacakan):

  • prd_bridge — kode acak untuk menghubungkan Penghubung AI milik Anda (hanya bila Anda memakainya).
  • prd_admin — khusus pengelola.
  • prd-generator:sb-auth (penyimpanan browser, bukan cookie) — menjaga Anda tetap masuk ke akun kredit sampai Anda keluar.

5. Berapa lama disimpan

  • File kerja sementara di server: dihapus otomatis ±2–3 jam.
  • Riwayat di browser: sampai Anda menghapusnya sendiri.
  • Akun kredit & pemakaian: selama akun aktif atau sampai Anda meminta penghapusan. Catatan pembelian tetap disimpan untuk keperluan pembukuan.

6. Keamanan

Koneksi memakai HTTPS, sesi login ditandatangani secara kriptografis, API key milik pengelola hanya disimpan di server (tidak pernah dikirim ke browser), API key Claude yang Anda tempel sendiri hanya disimpan di browser Anda dan tidak disimpan di server, dan daftar pengguna hanya bisa dilihat pengelola. Tidak ada sistem yang 100% aman; bila terjadi insiden yang memengaruhi data Anda, kami akan memberi tahu sesuai ketentuan UU PDP.

7. Hak Anda

Sesuai UU PDP, Anda berhak:

  • mengetahui dan meminta salinan data pribadi Anda yang kami simpan;
  • meminta perbaikan data yang keliru;
  • meminta penghapusan data dan berhenti memakai layanan;
  • menarik persetujuan (mis. mencabut akses aplikasi ini di pengaturan akun Google Anda: myaccount.google.com → Keamanan → Aplikasi pihak ketiga).

Ajukan permintaan ke kontak pengelola yang tercantum di web ini. Kami akan menanggapinya dalam waktu yang wajar (paling lambat 3 × 24 jam hari kerja untuk konfirmasi penerimaan).

8. Anak-anak

Layanan ini tidak ditujukan untuk anak di bawah 17 tahun tanpa pendampingan orang tua/wali.

9. Perubahan kebijakan

Bila kebijakan ini berubah, tanggal "Terakhir diperbarui" di atas akan diganti. Perubahan penting akan diberitahukan di web ini.
