Tutorial PRD Generator

Dari ide sampai aplikasi jadi, langkah demi langkah. Tidak perlu bisa ngoding: kamu menulis ide, AI menyusun rencananya (PRD), lalu aplikasi AI coding yang membangunnya. Gambar di halaman ini adalah contoh; isi di layarmu akan mengikuti idemu.

🧭 Di dalam web juga ada panduan interaktif: di setiap tahap, tombol yang penting disorot satu per satu dan diberi tahu "habis ini klik apa". Muncul sendiri saat pertama kali, dan bisa dipanggil lagi lewat tombol Habis ini apa? di pojok kanan bawah.

1. Siapkan mesin AI

Web butuh satu "mesin AI" untuk berpikir. Saat pertama dibuka (versi GitHub Pages), muncul kotak Belum ada mesin AI yang siap. Pilih salah satu:

  1. API key Claude (paling mudah, bisa dari HP): buat di console.anthropic.com → API Keys, tempel (diawali sk-ant-), klik Simpan.
  2. Gemini / OpenAI / SumoPod: buka API key lain, tempel key-nya, Simpan.
  3. agy / Claude CLI / Codex di PC (tanpa API key): lihat langkah penghubung di bawah.

Key hanya disimpan di browser itu. Mau ganti mesin, model, atau key nanti? Klik tombol ⚡ Mesin AI di kotak ide.

Pakai agy / Claude CLI / Codex dari PC:

  1. Pasang & login agy (Antigravity), Claude Code, atau Codex di PC.
  2. Buka web ini di Chrome/Edge di PC yang sama → Mesin AI → Pakai agy / Claude CLI / Codex dari komputer saya → Download penghubung.
  3. Ekstrak ZIP, klik dua kali Jalankan-Penghubung.bat (Node.js dipasang otomatis kalau belum ada). Biarkan jendelanya terbuka. Supaya tidak repot, klik Nyalakan-Otomatis.bat sekali: penghubung menyala sendiri setiap PC dinyalakan.
  4. Kalau browser bertanya soal akses ke perangkat/jaringan lokal, pilih Izinkan. Status jadi hijau → pilih mesinnya di menu Mesin AI.

2. Tulis ide

Di halaman awal, pilih Rencana aplikasi (PRD), lalu ceritakan aplikasimu dengan bahasa sehari-hari: siapa penggunanya, masalah apa yang diselesaikan, fitur yang terbayang. Klik tombol panah (atau Ctrl+Enter).

Belum punya ide? Gulir ke bawah ke "Contoh hasil", lalu klik "Coba ide ini".

3. Jawab pertanyaan AI

AI bertanya beberapa hal supaya tidak menebak. Pilih jawaban atau ketik sendiri. Tidak tahu? Klik Lewati. Lalu klik Lanjut (AI bisa bertanya sedikit lagi) atau Langsung bikin struktur.

4. Cek peta aplikasi (struktur)

AI menggambar peta fitur aplikasimu per fase. Klik fitur untuk mengubah atau menghapusnya, atau klik + Fitur untuk menambah. Kalau sudah pas, klik Bikin PRD.

5. Baca & periksa PRD

PRD (dokumen rencana aplikasi) ditulis AI. Bisa diedit, disalin, atau diunduh sebagai PDF/Word lewat menu Unduh. Di PC, daftar isi ada di kiri.

Klik Periksa kualitas PRD: AI memberi skor 0–100 dan daftar saran. Centang saran yang mau dipakai, lalu klik Perbaiki otomatis. Setelah itu klik Lanjut ke Task.

6. Task pengerjaan

PRD dipecah jadi daftar pekerjaan berurutan untuk AI coding. Boleh diedit. Klik Lanjut ke Paket Build.

7. Paket Build & bangun aplikasinya

AI menyiapkan semua dokumen: PRD, desain, prototype yang bisa diklik, task, dan aturan untuk AI coding. Tunggu sampai semuanya siap, lalu klik Download Paket Build (.zip).

Lalu ikuti 3 langkah di kotak paling atas:

  1. Ekstrak ZIP-nya ke satu folder.
  2. Buka folder itu di aplikasi AI coding (disarankan Claude Code).
  3. Klik Copy pada perintah yang disediakan, tempel di kotak chat AI coding, tekan Enter. AI coding mengerjakan task satu per satu.

8. Video langsung jadi

Pilih tab Video langsung jadi, tulis isi videonya, pilih format (9:16 untuk TikTok/Reels/Shorts). Centang Mode cerita kartun untuk video 2–3 tokoh yang bergantian bicara. Klik tombol buat.

AI menyusun storyboard: adegan, narasi, tokoh, latar, kamera. Kamu bisa mengubah tokoh (gaya, kostum, rambut, suara) dan tiap adegan, melihat pratinjau, lalu render MP4 (versi PC) atau download project (ZIP) untuk dirender di komputer. Caption media sosial juga dibuatkan.

9. Fitur tambahan

  • Dari video (Opsi lanjutan → 🎞 Dari video): upload rekaman layar aplikasi → jadi ide PRD; atau video yang kamu suka → video serupa / prompt teks.
  • Riwayat PRD (ikon jam di atas): buka lagi PRD lama, ekspor/impor riwayat.
  • Tema: tombol Ceria/Neon di atas.
  • Opsi lanjutan: referensi aplikasi, skill, bahasa, template, pilihan teknologi.

10. Panduan interaktif

Seperti di game: bagian yang penting disorot, ada penjelasan singkat, dan langkah terakhir menunjuk tombol berikutnya ("Habis ini: klik tombol ini"). Klik Lanjut untuk melihat sorotan berikutnya, atau langsung klik tombol yang disorot.

Kalau ada masalah

  • "Belum ada mesin AI yang siap": tempel API key (langkah 1), atau jalankan penghubung lalu tunggu statusnya hijau.
  • API key ditolak: key salah/terhapus, atau saldo akun penyedia habis. Buat key baru lalu tempel ulang.
  • Penghubung tidak tersambung: pastikan jendela penghubung masih terbuka, web dibuka di PC yang sama (bukan HP), pakai Chrome/Edge, dan izin akses perangkat diizinkan. Kalau perlu, download ulang penghubungnya.
  • Tampilan masih versi lama: tutup tab lalu buka lagi, atau tekan Ctrl+F5 (HP: tarik ke bawah untuk muat ulang).
  • Hasil AI berhenti di tengah: klik "Generate ulang" / "Coba lagi". Jawaban dan struktur tetap tersimpan.
